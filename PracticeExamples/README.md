# SOLID Principles and Design Patterns Practice

This folder contains hands-on practice examples for SOLID principles and common design patterns.

## Structure

### 1. SOLID Principles (5 principles)

- **S** - Single Responsibility Principle
- **O** - Open/Closed Principle
- **L** - Liskov Substitution Principle
- **I** - Interface Segregation Principle
- **D** - Dependency Inversion Principle

### 2. Design Patterns (5 patterns)

- **Singleton** - Ensures a class has only one instance
- **Factory Method** - Creates objects without specifying exact class
- **Observer** - Defines dependency between objects
- **Strategy** - Defines family of algorithms
- **Decorator** - Adds behavior to objects dynamically

## How to Practice

Each file contains:

1. **Explanation** - What the principle/pattern is about
2. **TODO sections** - Where you need to write code
3. **Hints** - Comments to guide your implementation
4. **Usage example** - How to test your code

Start with SOLID principles, then move to design patterns!
